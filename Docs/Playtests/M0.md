# M0 checklist — the project compiles and opens

Historical skeleton checklist. The current branch includes M1 source; after
building, run `Tools/Prepare.bat` and follow [M1.md](M1.md). Its tank replaces
the empty default level mentioned below. M0's first on-machine compile and
self-check still need confirmation.

Nothing to play yet. This milestone proves your machine can build the project
and that the engine-free core behaves identically on your compiler.

## Steps

1. Complete [SETUP.md](../SETUP.md) steps 1–4.
2. Double-click `Tools\Build.bat`.
   - **Expected:** `==== BUILD SUCCEEDED ====`
3. Double-click `Paleotrench.uproject`.
   - **Expected:** the Unreal Editor opens with an empty default level.
4. In the editor, open **Window → Output Log**. In the log's search box type
   `LogPaleotrench`.
   - **Expected:** one line reading
     `Paleotrench core 0.1.0 linked - self-check PASSED`
5. Open **Edit → Project Settings → Maps & Modes**.
   - **Expected:** *Default GameMode* shows `PaleotrenchGameMode`.
