# M3 — generated caves

**Status: implemented; builds on Unreal 5.7; your playtest pending.**
The engine-free cave generator has 14 new core tests (73 in total, all passing with warnings treated as
errors), covering 2000 seeds with the default tuning and 300 seeds for each of the four boss caves.

Every save now has its own cave. The layout, the rock, the air pockets and the route to the boss arena all
follow from the save's seed, so the same save always gives the same cave and a new game gives a new one.

## Get the build

Close Unreal, run `Tools/Build.bat`, then `Tools/Prepare.bat`, then open `Paleotrench.uproject`. Open the
new map **M3_Cave** (Content/Maps) and press **Play**. `M1_TestTank` still works as before.

## What is in a cave

- **The entrance**: you start in its air pocket, head above the water. It is also the first checkpoint and
  the depth reference (0 m on the wrist computer).
- **Chambers** of different sizes, some flat and wide, some tall, with flat silt floors. Faint
  coloured glows low on some walls let you read a chamber's shape with the lamp off.
- **Passages** between them: tunnels (about 4 to 6 m across), **squeezes** (about 2.4 m, always an
  alternative to a wider route) and steep **shafts**.
- **Air pockets** (domes in chamber ceilings) placed so you are never more than a set swim from air.
  Each one is a checkpoint, as in the test tank.
- **The arena**: the largest chamber, always the longest swim from the entrance, and never reachable
  through a single passage only, so you can't be cut off. Bosses come later (M7 to M10).
- Dead-end rooms are reserved for mining (M5) and creature nests (M4); they look like chambers for now.
- The rock streams in around you as you swim and unloads far behind.

The four caves differ through `Data/CaveTuning.csv`:

| Cave | Character |
|---|---|
| Livyatan, the Drowned Cathedral | huge open chambers, long swims, few squeezes |
| Tusoteuthis, the Ink Galleries | tall and narrow: many vertical shafts and squeezes |
| Stygiomedusa, the Black Veil | big dark chambers, air far apart, very dim glows |
| Arthropleura, the Breathing Tunnels | a low, flat maze of small chambers with many loops |

M3_Cave shows cave 1 (Livyatan). To see another, select **Generated Cave** in the level and set
**Cave Id** to 2, 3 or 4.

## Console commands

| Command | Effect |
|---|---|
| `pt.Cave` | Print the save seed, the cave and its size (rock chunks loaded, navigation state) |
| `pt.Cave new` | Start over in a new random cave |
| `pt.Cave abyss` | Start over in the cave of save seed "abyss" (any words or a number) |
| `pt.CavePath` | Draw the swimmable route from you to the arena for 30 seconds |

All earlier commands (`pt.Oxygen`, `pt.Lamp`, `pt.Body`...) still work. `pt.NewGame` also builds a new cave.

## Acceptance checks

| Check | Expected result |
|---|---|
| Play M3_Cave; Output Log filtered by `LogPaleotrench` | `Cave ready in ... ms: The Drowned Cathedral (cave 1), seed ...`, with no warnings. |
| Look around at the start | You are in a dome of air above water; dive down into a rock chamber with passages leading off. |
| Swim into walls, floors and ceilings | Solid everywhere; no holes or seams between rock pieces. |
| Swim through a squeeze | Tight but passable. |
| `pt.CavePath`, follow the line | It leads through open water to a huge chamber (the arena). |
| Swim a long way | No pop-in at short range; no hitches while new rock appears. |
| Find another air pocket | `CHECKPOINT SAVED`; black out later and you wake there. |
| Stop and press Play again | The same cave, from your last checkpoint. |
| `pt.Cave new` | A different cave; you start in its entrance. |
| `pt.Cave abyss`, note the layout, then `pt.Cave abyss` again | The same cave both times. |
| Lamp off (F) in a chamber | Dark, apart from faint glows on the walls. |

Things that are not there yet: creatures (M4), minerals and pickups in the cave (M5), and
hand-authored set-piece rooms. The rock is a plain greybox material.

## Debugging a cave from a bug report

`Tools/CaveGen.bat <save seed> --cave 1` prints the layout of any cave as the game builds it, with a top
and a side view; add `--svg cave.svg` for a drawing. `pt.Cave` prints the save seed to quote.

## Adjust the numbers

`Data/CaveTuning.csv` has one row per boss cave. Edit it, then close Unreal and run `Tools/Prepare.bat`,
or ask me to reimport it into the open editor. A new row value is checked against every rule for
hundreds of seeds by `Tools/RunCoreTests.bat` before you play it.

| Columns | What they control (lengths in cm) |
|---|---|
| `MinChambers`, `MaxChambers` | how many chambers |
| `RegionLength`, `RegionWidth`, `RegionHeight` | the space the cave fills |
| `ChamberRadiusMin/Max`, `ArenaRadius`, `ChamberGap` | chamber sizes and the rock between them |
| `TunnelRadiusMin/Max`, `SqueezeRadius`, `SqueezeChance`, `ShaftSlope` | passages |
| `MaxPassageLength`, `CandidateNeighbours`, `LoopFraction` | how far passages reach and how many alternative routes |
| `MaxAirSwim` | the longest swim to air from anywhere |
| `SideRoomChance` | share of dead ends that become mineral rooms or nests |
| `BlendRadius`, `LumpStrength/Size`, `DetailStrength/Size`, `ChamberNoiseShare`, `PassageNoiseShare` | how rough the rock is (noise can never close a passage) |
| `VoxelSize`, `ChunkCells`, `StreamRadius`, `KeepRadius` | rock detail and how far it streams |
| `GlowLumens`, `GlowsPerChamber` | the wall glows |
